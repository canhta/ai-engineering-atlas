## Domains

| Domain | Scope | Default depth |
| --- | --- | --- |
| [Software Engineering](01-software-engineering/) | Programming, testing, architecture, delivery | L2 |
| [Systems](02-systems/) | OS/concurrency, networking, storage, distributed systems, cloud, observability | L2 |
| [Data Engineering](03-data-engineering/) | Modeling, pipelines, quality, lineage, lifecycle | L1–L2 |
| [ML Foundations](04-ml-foundations/) | Math, statistics, classical ML, experimentation | L1–L2 |
| [Deep Learning](05-deep-learning/) | Neural networks, optimization, backpropagation, representations | L2 |
| [LLM Foundations](06-llm-foundations/) | Tokenization, transformers, attention, inference, context | L2–L3 |
| [AI Engineering](07-ai-engineering/) | Product framing, model selection, retrieval, evaluation, adaptation | L2–L3 |
| [Agents](08-agents/) | Tools, workflows, state, memory, planning, MCP, agent eval | L2–L3 |
| [Production AI](09-production-ai/) | Gateways, tracing, releases, reliability, latency, cost | L3 |
| [Security & Governance](10-security-governance/) | Prompt injection, authorization, privacy, supply chain, governance | L2 |
| [Multimodal](11-multimodal/) | Vision, audio, voice, documents, multimodal retrieval | L1–L2 |
| [Specializations](12-specializations/) | LLM systems, post-training, search, platform, dev tools | Optional |

A domain page is a scope/navigation map even when it has no ready route yet.

Do not treat a scope bullet or catalog item as finished learning content.
