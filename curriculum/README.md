# Curriculum

The curriculum is grouped by domain. The numbering provides a reasonable reading order; it is not a requirement to study every domain sequentially.

| Domain | Scope | Default depth |
| --- | --- | --- |
| [Software Engineering](01-software-engineering/) | Programming, testing, architecture, OS, networking, databases | L2 |
| [Systems](02-systems/) | Distributed systems, reliability, performance, cloud, observability | L2 |
| [Data Engineering](03-data-engineering/) | Modeling, pipelines, batch/stream processing, quality, lineage | L1–L2 |
| [ML Foundations](04-ml-foundations/) | Math, statistics, classical ML, experimental design | L1–L2 |
| [Deep Learning](05-deep-learning/) | Neural networks, optimization, backpropagation, representations | L2 |
| [LLM Foundations](06-llm-foundations/) | Tokenization, transformers, attention, inference, context | L2–L3 |
| [AI Engineering](07-ai-engineering/) | Model selection, context, retrieval, evaluation, adaptation | L2–L3 |
| [Agents](08-agents/) | Tool use, workflows, state, memory, MCP, agent evaluation | L2–L3 |
| [Production AI](09-production-ai/) | Serving, gateways, tracing, reliability, latency, cost | L3 |
| [Security & Governance](10-security-governance/) | Prompt injection, authorization, privacy, supply chain | L2 |
| [Multimodal](11-multimodal/) | Vision, audio, voice, documents, multimodal retrieval | L1–L2 |
| [Specializations](12-specializations/) | LLM systems, post-training, reasoning, search, AI platforms | Optional |

See [../CURRICULUM.md](../CURRICULUM.md) for the competency contract.
