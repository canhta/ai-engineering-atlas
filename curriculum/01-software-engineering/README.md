# Software Engineering

Core software engineering knowledge that AI systems rely on.

## Scope

- programming language fundamentals
- data structures and algorithms
- testing and debugging
- operating systems and concurrency
- networking and APIs
- relational and non-relational databases
- software architecture and maintainability
- delivery practices, version control, and Linux tooling

The goal is not to repeat a complete CS degree. Use diagnostics to identify gaps that materially affect AI engineering work.
