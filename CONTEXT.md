# AI Engineering Atlas

A gap-driven roadmap that routes software engineers through exact external sources and records what they demonstrate. This glossary fixes the words used in the curriculum, the web atlas, and agent work.

## Language

**Competency**:
One capability in the catalog, with a stable ID.
_Avoid_: skill, topic, node, lesson

**Ready route**:
A competency whose full learning-route contract is met (catalog `status: ready`), so it has a page.
_Avoid_: course, lesson, module

**Mapped competency**:
A competency in the catalog with no ready route yet. Learners see "mapped"; the catalog stores it as `status: coverage`. They are one concept.
_Avoid_: planned, placeholder, locked, coming soon

**Learner state**:
Where a learner stands on a competency (gap, learning, demonstrated, transferred, retained, applied), changed only by an evidence record.
_Avoid_: progress percentage, completion, done

**Evidence record**:
What a learner produced or showed for a competency, which is the only thing that moves a learner state.
_Avoid_: completion, check-off

**Plate**:
The atlas map: one tile per competency, grouped by domain.
_Avoid_: grid, graph, skill tree
