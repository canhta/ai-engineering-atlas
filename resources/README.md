# Resources

External material is stored separately from curriculum competencies.

A resource should answer two questions:

1. Which competency does it support?
2. What role does it play?

## Roles

- **primary** — main source for learning the topic
- **visual** — visual or interactive explanation
- **practice** — exercises, notebooks, or implementation material
- **reference** — deeper or supplementary material
- **benchmark** — used to audit curriculum coverage or repository design

Prefer official course pages, author repositories, documentation, and primary sources where practical.
