# AI assistance policy

AI tools may assist with learning and repository maintenance, but curriculum changes must remain traceable to reviewed sources.

## Appropriate uses

AI may:

- extract structure from approved sources
- summarize verified material
- generate questions from approved material
- review code and experiments
- propose diagrams and visualizations
- suggest resource mappings
- draft an RFC for review

## Changes that require review

AI should not directly make the following changes without supporting evidence and review:

- add or remove required competencies
- change prerequisites
- change target competency levels
- change exit criteria
- promote a resource to primary status

Public-facing writing and layout must also follow [AGENTS.md](AGENTS.md).
