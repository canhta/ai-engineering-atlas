# Assessments

Assessments exist to make learning decisions and collect evidence.

They are not intended to turn the roadmap into a school-style grading system.

## Types

### Baseline scan

Broad routing assessment used before choosing a domain.

See [baseline.md](baseline.md).

### Competency diagnostic

Runs before instruction. It should reveal whether the learner needs the full learning route, a targeted patch, or can move directly to exit/transfer work.

Diagnostics live with the competency when they are specific to that capability.

### Exit evidence

Proves the stated outcome immediately after learning or practice.

### Transfer task

Changes the context enough to test whether the learner can adapt rather than copy a learned pattern.

### Delayed retrieval

Checks whether important knowledge can be reconstructed later without rereading first.

### Applied evidence

Shows that the capability affected an integrated or real system.

### Portfolio review

A periodic integration checkpoint after a meaningful cluster of work.

It combines learner-state evidence, project artifacts, failure analysis, design choices, and reflection about what still fails to transfer.

See [portfolio-review.md](portfolio-review.md).
