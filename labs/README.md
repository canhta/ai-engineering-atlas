# Labs

Labs turn a competency into an inspectable task.

A lab is not automatically required for every competency. It is useful when the capability needs implementation, debugging, experimentation, or a concrete artifact.

## Packaging

A mature lab may include:

- `README.md` — task, constraints, evidence, challenge;
- `starter.*` — incomplete learner starting point;
- `tests.*` — checks the learner can run;
- `solution.*` — reference solution when appropriate;
- small fixtures or datasets.

The solution should not be the default learning path. Attempt the task first.
