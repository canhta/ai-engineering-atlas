# <Lab>

Companion practice for `<competency-id>`.

## Goal

State the capability the learner should demonstrate.

## Starting point

Describe provided starter state, fixtures, and environment.

Do not hide core reasoning behind setup work.

## Task

Give constraints and expected behavior without giving away the implementation.

## Runnable checks

When appropriate, provide tests or commands that check observable behavior.

Tests should not be the only evidence when reasoning/debugging is part of the competency.

## Failure work

Ask the learner to inject, diagnose, or recover from one meaningful failure.

## Experiment

Change one variable, make a prediction, measure the result, and explain it.

Remove this section if experimentation does not add learning value.

## Transfer challenge

Change context enough to require adaptation.

Remove this section if transfer is not a target state.

## Evidence

State exactly what artifacts justify the relevant learner-state transition.

## Reference solution

If a solution exists, place it behind an explicit link and tell the learner to attempt the task first.
